# Jarvis Brook Skatepark Extension

Campaign website for the proposed Jarvis Brook Skatepark extension in Crowborough, East Sussex.

## Publish on GitHub Pages

Upload all files and the `images` folder to the root of the `jbskatepark.github.io` repository. GitHub Pages will publish the site automatically from the `main` branch.

## Updating the fundraising link

In `index.html`, find:

`Fundraising link — TBC`

Replace the surrounding `<span>` with an `<a>` element containing the live fundraising URL.
